# infra-monitoring-project

Инфраструктура мониторинга для echo-API: проверка доступности сервиса, анализ access-логов, контейнеризированный стек (API + nginx-прокси) и CI-пайплайн на GitHub Actions.

## Ветки

- `main` — защищённая ветка, изменения попадают только через Pull Request.
- `feature/monitoring` — рабочая ветка.
